# Repository working instructions

Read [AGENTS.md](AGENTS.md), then [memory/INDEX.md](memory/INDEX.md).
These are the shared instructions for this fork. Resume from the named
checkpoint and load only missing task context.

Claude Code uses project-local `.mcp.json`, generated by
`python scripts/setup_project_memory.py --cm-command <absolute-executable>`.
Check the actual enabled server and DB before use; configuration on disk does
not prove an already-running client has reconnected.

`/memory` in the engineering documents means this repository's `memory/`
directory. The client's built-in `/memory` command remains an instruction-file
editor; this project does not redefine it or install a second memory skill.

Upstream examples under `integrations/` and `skills/` describe the product,
not authorization to install global hooks, use a shared default DB, or extract
conversations automatically for this repository. The original generic prompt
is preserved in Git at the bootstrap source revision.
